# 🌿 내 사주 오행 테스트 — 윤이세사주

리틀리(`litt.ly/yoonise`)의 **[무료사주] 내 사주 오행 테스트**에 연결하는 정적 웹앱입니다.
빌드 서버가 필요 없고, 폴더를 그대로 GitHub Pages(또는 아무 정적 호스팅)에 올리면 바로 동작합니다.

---

## 1. 폴더 구조

```
oheng-aroma-app/
├─ index.html            ← 앱 화면 (유일한 진입점)
├─ assets/
│  ├─ style.css          ← 디자인 (다크 차콜·크림·라일락/세이지)
│  ├─ app.js             ← 입력·렌더링·복사 로직
│  ├─ manse.js           ← 만세력 계산 엔진 (연·월·일·시주, 오행 분포)
│  └─ data.js            ← 아키타입 10종 · 아로마 15종 · 루틴 문구
└─ vendor/
   └─ lunar.js           ← lunar-javascript v1.7.8 (MIT, 로컬 번들 · CDN 불필요)
```

외부 요청은 **하나도 없습니다.** 폰트·이미지·스크립트 모두 로컬/시스템 자원만 사용하고,
입력한 생년월일은 브라우저 안에서만 계산되며 어디에도 전송·저장되지 않습니다.

## 2. 배포 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다 (예: `oheng-test`). Public이어야 무료 Pages를 쓸 수 있습니다.
2. 이 폴더의 **안쪽 내용**(`index.html`, `assets/`, `vendor/`)을 저장소 최상위에 올립니다.
3. 저장소 → **Settings → Pages** → Source `Deploy from a branch`, Branch `main` / `/ (root)` → Save.
4. 1~2분 뒤 `https://<아이디>.github.io/oheng-test/` 에서 열립니다.
5. 리틀리 관리자 → 링크 블록에 위 주소를 넣으면 손님에게 연결됩니다.

> 저장소 이름을 `아이디.github.io` 로 만들면 주소가 `https://아이디.github.io/` 로 짧아집니다.

## 3. 로컬에서 확인

```bash
cd oheng-aroma-app
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
(파일을 더블클릭해 `file://` 로 열어도 동작합니다.)

## 4. 계산 방식 — 무엇을 어떻게 반영했나

| 항목 | 처리 |
| --- | --- |
| 연주 | **입춘(立春) 절입 시각**을 기준으로 바뀝니다. (양력 1월 1일 아님) |
| 월주 | **12절기**(입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설·소한)의 **절입 시각** 기준 |
| 일주 | 율리우스 적일 기반 60갑자. 기본은 **자시가 시작되는 23:30(조자시설)** 에 날짜가 바뀌며, 고급 설정에서 자정 기준으로 바꿀 수 있습니다. |
| 시주 | **한국 사주명리 표준 12지시(30분 경계)** + 오자둔(五鼠遁). 자시 23:30~01:30, 오시 11:30~13:30, 미시 13:30~15:30처럼 30분씩 밀린 경계를 씁니다. **'시간 모름'** 을 켜면 년·월·일 6글자로 계산합니다. |
| 음력 | 음력 입력과 **윤달** 변환 지원 (없는 윤달을 고르면 안내 문구로 막아 줍니다) |
| 시각 보정 | ① **진태양시 보정** — 표준자오선 135°E와 출생지 경도의 차이만큼 빼기(서울 ≈ −32분, 부산 ≈ −24분). 기본은 꺼짐(표준시 그대로). ② **서머타임(−1시간)** — 1987·1988년 여름 출생용 체크박스. |
| 절입일 출생 + 시간 모름 | 절입 전/후 두 가지 연·월주를 함께 보여 주고, 정오 12:00 기준으로 계산했음을 명시합니다. |

절입 시각은 라이브러리 계산값(중국 표준시 UTC+8)을 **절대 시각으로 환산해 한국 표준시(UTC+9)와 비교**합니다.
그래서 화면에 표시되는 절입 시각이 한국천문연구원(KASI) 표기와 분 단위로 일치합니다.

## 6. 입력 항목 메모

- **성별**은 이제 **필수 선택**입니다(선택하지 않으면 안내 문구와 함께 제출이 막힙니다). 계산식에는 아직 쓰이지 않고, 대운·궁합 확장용으로 값만 받습니다.
- **진태양시 보정**은 기본 꺼짐입니다. 켜면 출생지 경도에 따라 서울 −32분, 부산 −24분처럼 자동 계산합니다.
- **일주 기준 시각**은 기본이 자시 시작 23:30(조자시설)입니다. 만세력마다 자정 기준을 쓰는 곳이 있어 고급 설정에서 바꿀 수 있게 했습니다.

## 9. 2026-11-19 개선 (v2)

- **성별 필수 선택**: `선택 안 함` 칩을 없애고 `여성` / `남성` 중 하나를 고르지 않으면 안내 문구(`성별을 선택해 주세요.`)와 함께 제출을 막습니다. 필수 표시 `*`와 입력 안내 문구를 함께 넣었습니다.
- **12지시 30분 경계**: 표기와 계산을 모두 한국 사주명리 표준 30분 경계로 바꿨습니다(자시 23:30~01:30 … 해시 21:30~23:30). 시지 인덱스는 `Manse.jisiIndex(hh, mm)` 하나로 계산하므로 칩 표시와 시주 계산이 어긋나지 않습니다. 조자시설의 일주 경계도 자시 시작인 23:30으로 맞췄습니다.
- **중간 카톡 CTA**: 02 아키타입 카드 바로 아래에 `💬 내 오행 밸런스, 지금 1:1로 짚어보기` 배너를 추가했습니다(하단 CTA는 그대로 유지).
