# 🌿 내 사주 오행 테스트 — 윤이세사주

리틀리(`litt.ly/yoonise`)의 **[무료사주] 내 사주 오행 테스트**에 연결하는 정적 웹앱입니다.
빌드 서버가 필요 없고, 폴더를 그대로 GitHub Pages(또는 아무 정적 호스팅)에 올리면 바로 동작합니다.

---

## 1. 폴더 구조

```
oheng-aroma-app/
├─ index.html            ← 앱 화면 (유일한 진입점)
├─ assets/
│  ├─ style.css          ← 디자인 (다크 차콜·크림·라일락/세이지)
│  ├─ app.js             ← 입력·렌더링·복사 로직
│  ├─ manse.js           ← 만세력 계산 엔진 (연·월·일·시주, 오행 분포)
│  └─ data.js            ← 아키타입 10종 · 아로마 15종 · 루틴 문구
└─ vendor/
   └─ lunar.js           ← lunar-javascript v1.7.8 (MIT, 로컬 번들 · CDN 불필요)
```

외부 요청은 **하나도 없습니다.** 폰트·이미지·스크립트 모두 로컬/시스템 자원만 사용하고,
입력한 생년월일은 브라우저 안에서만 계산되며 어디에도 전송·저장되지 않습니다.

## 2. 배포 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다 (예: `oheng-test`). Public이어야 무료 Pages를 쓸 수 있습니다.
2. 이 폴더의 **안쪽 내용**(`index.html`, `assets/`, `vendor/`)을 저장소 최상위에 올립니다.
3. 저장소 → **Settings → Pages** → Source `Deploy from a branch`, Branch `main` / `/ (root)` → Save.
4. 1~2분 뒤 `https://<아이디>.github.io/oheng-test/` 에서 열립니다.
5. 리틀리 관리자 → 링크 블록에 위 주소를 넣으면 손님에게 연결됩니다.

> 저장소 이름을 `아이디.github.io` 로 만들면 주소가 `https://아이디.github.io/` 로 짧아집니다.

그래서 화면에 표시되는 절입 시각이 한국천문연구원(KASI) 표기와 분 단위로 일치합니다.

## 6. 입력 항목 메모

- **성별**은 이제 **필수 선택**입니다(선택하지 않으면 안내 문구와 함께 제출이 막힙니다). 계산식에는 아직 쓰이지 않고, 대운·궁합 확장용으로 값만 받습니다.
- **진태양시 보정**은 기본 꺼짐입니다. 켜면 출생지 경도에 따라 서울 −32분, 부산 −24분처럼 자동 계산합니다.

## 12. 타이밍 캘린더(`calendar/`) — 2027 정미년 대표 부적 + 톡·톡·톡 리추얼

- **1년 대표 수호 부적**: 원국 8글자(시간 모르면 6글자)의 오행 분포에서 **가장 적은 오행** 한 가지를 골라 `2027 정미년 대표 수호 부적`으로 배정합니다. 0개면 "하나도 없어요", 1개 이상이면 "가장 적어요"로 이유를 붙입니다. 동률이면 **인성 → 비겁 → 식상 → 재성 → 관성** 순(나를 도와주는 기운부터)으로 하나만 고르고, 그 사실을 카드 하단에 적습니다. 계산은 `calendar/assets/calendar.js` 의 `repElement()`.
- **부적 5종 ↔ 배지 매칭**: 럭키 `wood`(목) · 입단속 `water`(수) · 결정 `fire`(화) · 머니 `metal`(금) · 리셋 `earth`(토). 이미지 원본은 `../oheng-talisman/01_wood.png`~`05_water.png`(9:16 카드)이고, 웹용은 카드 폭 전체를 캐릭터 중심으로 정사각 크롭해 480px JPG로 줄여 `calendar/assets/talisman/` 에 두었습니다(`oheng-talisman/make_web_thumbs.py`).
- **톡·톡·톡 리추얼(단계별 연출)**: 날짜를 열면 팝업의 주인공은 글자가 아니라 **부적 캐릭터(196px)** 입니다. 부적을 두드릴 때마다 `data-stage`가 0→1→2→3으로 바뀌며 표정 배지(`✨ → ⚡ → 🔥 → 오행 배지 🌱💖⭐💎💧`), 기운 오라 크기, 볼 발그레, 몸 떨림이 함께 바뀌고, 매 타마다 **젤리 바운스**(`@keyframes jelly` / `jellyBig`) · **터치 지점 파문 링** · **오행 파티클 폭발** · **모달 흔들림**(`is-quake` / `is-quake--big`)이 터집니다. 진동은 1·2타 `[45,25,55]`, 3타 완료 `[80,35,100,45,130]`. 3/3에서 상태별 완료 대사와 함께 달력 칸에 **주홍 낙관 도장**(`SEAL_SVG` — 채운 원 + 크림 점선 테두리 + 네 귀퉁이 금색 별)이 쾅 찍히고, 완료 뒤에도 캐릭터 주위에 잔불처럼 반짝임이 남습니다.
